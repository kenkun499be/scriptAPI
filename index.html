燃やす

エンティティやプレイヤーを燃やすことができます
ここではtagがついている人を燃やすコードを紹介します


system.runInterval(() => {
    for (const entity of mc.world.getDimension("overworld").getEntities({tags:["fire"]})) {
        entity.setOnFire(10, true);
        entity.runCommand("tag @s remove fire");
    }
});

名前変更

エンティティやプレイヤーの名前を変更できます
ここではtagにaaaがついているエンティティの名前をaaaに変更するコードと、tagにredがついてる人の名前を赤にするコードを紹介します


system.runInterval(() => {
    for (const entity of mc.world.getDimension("overworld").getEntities({tags:["aaa"]})) {
        entity.nameTag = `aaa`
    }
});
      

system.runInterval(() => {
    for (const entity of mc.world.getDimension("overworld").getEntities({tags:["red"]})) {
        entity.nameTag = `§c${entity.name}`
    }
});

行動検知

エンティティやプレイヤーの行動を検知できます
ここではプレイヤーがジャンプするとコマンドを実行するコードを紹介します
※isJumpingをisSneaking等に変えることで別の行動も検知できます


system.runInterval(() => {
    for (const player of world.getAllPlayers()) {
        if (player.isJumping) player.runCommand(`say jumping`);
    }
});

名前検知,代入

エンティティやプレイヤーの名前を検知できます
ここではプレイヤーが自分の名前を言い続けるコードを紹介します


system.runInterval(() => {
    for (const player of world.getAllPlayers()) {
        player.runCommand(`say ${player.name}`);
    }
});

ノックバック

エンティティやプレイヤーをノックバックさせます
ここでは棒を使用すると前に飛ぶコードを紹介します


world.afterEvents.itemUse.subscribe(ev => {
    const { source, itemStack } = ev
    if (itemStack.typeId === "minecraft:stick") {
      const view = source.getViewDirection()
      source.applyKnockback(view.x, view.z, 6, view.y * 3)
    }
  })

殴り検知

殴った人と殴られた人を検知できます
ここでは殴られた人に殴った人の名前のtagを付与するコードを紹介します


world.afterEvents.entityHitEntity.subscribe(({hitEntity , damagingEntity}) => {
    hitEntity.addTag(`${damagingEntity.name}`)
  });
