ScriptAPIの初期設定

ScriptAPIを使うにはまずワールドにモジュールをインポートして初期化します。基本的なイベント購読もここで行えます。


// ScriptAPI 初期設定例
import { world } from "mojang-minecraft";

world.events.entitySpawn.subscribe(event => {
    console.log("Entity spawned:", event.entity.id);
});

プレイヤー操作の例

ワールド内のプレイヤー情報を取得したり、操作する場合のサンプルです。全プレイヤーの名前をコンソールに出力します。


// プレイヤー情報取得
import { world } from "mojang-minecraft";

world.getPlayers().forEach(player => {
    console.log("Player name:", player.name);
});
